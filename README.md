## Built With
- Node.js + Express 5
- EJS templates (with partials)
- Bootstrap 5
- Google Sheets API (service account)
- Jest + Supertest, CircleCI, Render

## Features
- Portfolio page generated from a data file
- Contact form with a personalized thank-you page
- Submissions logged to a Google Sheet

## Run Locally
```bash
git clone https://github.com/trentgardner/Personal_Portfolio.git
cd Personal_Portfolio
npm install
npm run dev
```
Then open http://localhost:3000
